💡 什么是 Token？

Token（词元）是 AI 能理解的最小文本单位。AI 不会逐个字母处理文字，而是把文本切成一块块的碎片，每一块就是一个 Token。

一个好记的比喻：把文章想象成一块 比萨🍕——你不会整块吞下，也不会碾成粉末，而是切成一口大小。Token 就是这个"一口大小"。

📐 Token 比单词更细，比字母更粗

• "cat" → 1 token（常见词）

• "unbelievable" → 3 tokens（un·believ·able）

• "ChatGPT" → 3 tokens（Chat·G·PT）

• "你好" → 2~3 tokens（中文消耗更多）

🔢 AI 行业 Token 计量：十进制

AI 行业严格遵循国际单位制十进制：

• 1K = 1,000 Token（不是 1,024）

• 1M = 1,000,000 Token（即 100 万）

这与计算机存储（KB=1024 Bytes）完全不同！

📊 常见上下文窗口

• GPT-3.5：4K   GPT-4o：128K

• Claude 3.5：200K   Gemini 1.5 Pro：2M

• 豆包 Pro：256K   通义千问-Long：10M

超过窗口限制，AI 就会"忘记"之前的内容。

💰 Token 影响费用和速度

• API 调用按输入+输出 Token 总量计费

• AI 生成文字是逐 Token 输出的，越长越慢

• 空格和标点也算 Token！

• 代码比自然语言更省 Token
